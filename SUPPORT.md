# Support for RouteCase

If you experience an issue, have a question, or would like to request a feature for **RouteCase**, here are the best channels to get help:

## Issue Tracker

To report a bug or request a feature:
1. Search existing issues on our GitHub repository: [RouteCase Issues](https://github.com/routecase/routecase/issues).
2. If your issue is not listed, submit a new issue with:
   - Your VS Code version.
   - Your Operating System.
   - A sanitized `.rcase` sample file reproducing the problem.
   - Expected vs actual behavior.

## Security Disclosures

To report a security vulnerability, please open a private security advisory on GitHub or email the maintainers directly.
